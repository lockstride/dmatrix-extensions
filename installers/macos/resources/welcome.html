This installs dMatrix decision capture into every AI client on this Mac — Claude Code, Codex CLI (which also covers the ChatGPT desktop app), and Antigravity CLI. Each one gets the plugin through its own plugin manager, so nothing here replaces or edits an app you already have.

Installing also sets up a daily check that keeps the plugin current, so you never have to update it by hand. It runs only the clients’ own update commands.

The Claude app, claude.ai, and ChatGPT on the web install against your account rather than this Mac, so they cannot be set up from here. The last screen links their steps.

You’ll need a free dMatrix account — sign up at dmatrix.com.
