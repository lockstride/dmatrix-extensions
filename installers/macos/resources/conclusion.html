Done. A notification just told you which clients were set up. The full per-client result is in:

/Library/Application Support/dMatrix/install.log

Start a new session in any of them and dMatrix will offer to capture a decision. Claude Code sessions that are already open need /reload-plugins; the ChatGPT desktop app needs a restart.

The Claude app and claude.ai, and ChatGPT on the web, install against your account and take a few clicks each:
github.com/oxford-heavy/dmatrix-extensions/blob/main/claude/README.md
github.com/oxford-heavy/dmatrix-extensions/blob/main/openai/README.md

To remove everything this installed, run these in Terminal. The first is deliberately not sudo — it removes the plugin and the daily check from your account, which is where they live:

"/Library/Application Support/dMatrix/install.sh" --uninstall
sudo pkgutil --forget com.dmatrix.extensions
sudo rm -rf "/Library/Application Support/dMatrix"
